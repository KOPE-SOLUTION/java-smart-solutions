### Playlist 2 — Java OOP in Action: Smart Factory Core

1. Class และ Object

3. Encapsulation และ Validation

5. Composition และ Value Object
6. Inheritance และ Abstract Class
7. Interface
8. Polymorphism
9. Collection, Optional และ Stream
10. Service Layer, Exception และ Test

### Playlist 3 — Java Desktop Workshop: Smart Factory Dashboard

1. JavaFX, Maven, Stage และ Scene

10. Task, Background Thread และ Timeline
11. FXML และ Controller
12. ภาษาไทย, Runtime Image และ IoT Roadmap
