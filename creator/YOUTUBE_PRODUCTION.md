## โครงสร้าง 3 Playlist

### Playlist 1 — Java Basic Lab: Smart Factory Console

1. ติดตั้ง JDK และโปรแกรม Java แรก
2. Variable, Data Type และ Constant
3. Operator และ Type Casting
4. String และ Output Formatting
5. รับข้อมูลด้วย Scanner
6. if/else และ Logical Operator
7. switch และ Console Menu
8. for, while และ do-while
9. Array และ Enhanced for
10. Method และ Smart Factory Console Capstone

### Playlist 2 — Java OOP in Action: Smart Factory Core

1. Class และ Object
2. Field, Method และ Constructor
3. Encapsulation และ Validation
4. Enum และ State
5. Composition และ Value Object
6. Inheritance และ Abstract Class
7. Interface
8. Polymorphism
9. Collection, Optional และ Stream
10. Service Layer, Exception และ Test

### Playlist 3 — Java Desktop Workshop: Smart Factory Dashboard

1. Swing, JFrame และ Event Dispatch Thread
2. JPanel และ Layout Manager
3. JLabel, JTextField และ JButton
4. Event-driven Programming และ Listener
5. JOptionPane และ Validation
6. JTable และ TableModel
7. Cell Renderer และ Summary Card
8. เชื่อม SmartFactoryService และ CRUD
9. Swing Timer และ UI Thread
10. ภาษาไทย, Packaging และ IoT Roadmap

## เหตุผลที่ใช้ Repository เดียว
