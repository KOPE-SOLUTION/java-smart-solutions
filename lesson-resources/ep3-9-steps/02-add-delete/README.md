# EP3.9 — จบตอนที่ 3 — เพิ่มและลบ

ซอร์สอ้างอิงสำหรับ [บทเรียนตอนที่ 3](../../../docs/playlist-03-java-desktop/ep09b-service-add-delete.md) ใช้ Java 21 และ JavaFX 21.0.10

เปิด Terminal ที่โฟลเดอร์หลักของ Repository แล้วรัน:

```powershell
.\mvnw.cmd -f .\lesson-resources\ep3-9-steps\02-add-delete\pom.xml javafx:run
```

เริ่มจากเครื่องจักร 3 เครื่อง เพิ่มข้อมูล ตรวจรหัสซ้ำ และลบแถวที่เลือกได้

ข้อมูลอยู่ในหน่วยความจำ เปิดโปรแกรมใหม่จะเริ่มจากข้อมูลเดิม การรันครั้งแรกต้องใช้อินเทอร์เน็ต
