# EP3.9 — จบตอนที่ 3 — การบำรุงรักษา

โปรเจกต์พร้อมรันด้วย Java 21 และ JavaFX 21.0.10 มี Source และ CSS ครบในโฟลเดอร์นี้

เปิด Terminal ที่โฟลเดอร์หลักของ Repository ซึ่งมี `mvnw.cmd` แล้วรัน:

```powershell
.\mvnw.cmd -f .\lesson-resources\ep3-9-steps\03-maintenance\pom.xml javafx:run
```

เมื่อเริ่มจะมี M-001, M-002 และ M-003 รวม 3 เครื่อง สถานะปกติ 2, Sensor ผิดปกติ 1 และหยุดฉุกเฉิน 0 โดยต้องบำรุงทั้งหมด 2 เครื่อง

ข้อมูลอยู่ในหน่วยความจำ ปิดและเปิดใหม่จะเริ่มจากข้อมูลเดิม การรัน Maven ครั้งแรกต้องใช้อินเทอร์เน็ต
