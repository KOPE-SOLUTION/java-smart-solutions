# EP3.9 — จบตอนที่ 4 — การบำรุงรักษา

ซอร์สอ้างอิงสำหรับ [บทเรียนตอนที่ 4](../../../docs/playlist-03-java-desktop/ep09c-service-maintenance.md) ใช้ Java 21 และ JavaFX 21.0.10

เปิด Terminal ที่โฟลเดอร์หลักของ Repository แล้วรัน:

```powershell
.\mvnw.cmd -f .\lesson-resources\ep3-9-steps\03-maintenance\pom.xml javafx:run
```

มีคอลัมน์ชั่วโมงและบำรุงรักษา เริ่มจากเครื่องจักร 3 เครื่องและต้องบำรุง 2 เครื่อง ปุ่มบำรุงเสร็จอัปเดตชั่วโมง สถานะ และจำนวนสรุป

ข้อมูลอยู่ในหน่วยความจำ เปิดโปรแกรมใหม่จะเริ่มจากข้อมูลเดิม การรันครั้งแรกต้องใช้อินเทอร์เน็ต
